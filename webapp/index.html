Share your agent skills,
one private repo at a time

skylls publishes every skill, agent and swarm you make for Claude Code, Codex and Gemini to its own private GitHub repo — and shares each one with exactly the friends you choose.

Private by default

Your skills, your repos, your rules

GitHub stores everything and decides who can see what. skylls adds versions, changelogs, plain summaries, folders, suggestions and a secret scan on top.

One private repo per item

Every skill, agent and swarm gets its own private repo — skill-pdf, agent-btc — created the first time you publish it. Nothing is shared until you share it.

Share item by item

skylls share pdf @bob lets Bob install that one skill — not your other skills, agents or swarms. Revoke any time. With an organization, friends get read-only access.

Secret scan before every push

API keys, tokens, passwords and personal data are caught with gitleaks before anything leaves your machine. If something is found, nothing is published.

Agents and swarms, with memory

Share a whole agent or swarm: its instructions, .claude/ and scripts plus its Obsidian memory — never its logs, data or private settings.

Versions and changelogs

Every push is a new version with a note of what changed, when and by whom, and a one-sentence summary written by Claude. Older versions stay installable.

Claude Code, Codex and Gemini

Install for one project or globally; one real copy plus links for every agent CLI you use. Folders, suggestions and --json output for agents included.

Quick start

From your machine to a friend's in a minute

Set up once, then publish, share and install with one command each.

Install & set up

Install with npm, then skylls setup. It recommends a free GitHub organization to hold your repos and shows you how to make one.

Publish

skylls push pdf scans for secrets and publishes your skill to its own private repo as v1.0.0. Agents and swarms: skylls agents push btc.

Share

skylls share pdf @bob invites Bob to that one repo — from the terminal or from the dashboard.

Your friend installs

Bob runs skylls source add you once, then skylls add pdf -g -a all. Updates arrive with skylls pull --update.

Organized on GitHub

An organization works like a folder

Every item is an independent private repo, so a friend you share one skill with can't see the rest. Group them further with folders (GitHub topics).

github.com/you-skylls ← your organization ├── skill-pdf private shared with @bob (read-only) ├── skill-invoices private folder: work ├── agent-btc private definition + Obsidian memory └── swarm-app-ideas private not shared

Two terminals

You share, your friend installs

Everything also works for agents and swarms: skylls agents …, skylls swarms ….

you 
# publish a skill (secret scan first)
$ skylls push pdf -m "Handles scans"
✓ No secrets or private info found.
✓ Published pdf v1.1.0 → you-skylls/skill-pdf

# share it with one friend
$ skylls share pdf @bob
✓ Invited @bob (read-only)

# answer their suggestions
$ skylls suggestions
pdf#3  Support Excel files  by @bob
$ skylls accept pdf#3 -m "Done in 1.2.0"
your friend 
# see what you shared (accepts the invite)
$ skylls source add you-skylls
✓ Added you-skylls: 1 skills

# install for Claude Code, Codex and Gemini
$ skylls add pdf -g -a all
✓ Installed 'pdf' → ~/.claude/skills/pdf

# later: get new versions
$ skylls pull --update
pdf: v1.1.0 → v1.2.0
